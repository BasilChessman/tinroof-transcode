# TinRoof Transcode (TRT)

A modern macOS video player, editor and converter in the spirit of MPEG Streamclip (Squared 5, 2008), written from scratch. It contains no code from the original.

The display name comes from `APP_NAME` in `scripts/build_app.sh` (default “TinRoof Transcode”); the app reads it from the bundle at runtime.

## Requirements

- macOS 14 or later, Apple Silicon or Intel
- Xcode 16+ or Command Line Tools with Swift 6
- `brew install ffmpeg pkg-config` (FFmpeg libraries are linked; the `ffmpeg` tool runs conversions)
- Optional: `brew install yt-dlp` (resolves web-page URLs in Open URL)

## Build, test, run

```sh
swift build                       # debug build
./scripts/make_test_media.sh      # generates TestMedia/ (MPEG-2/AC3 5.1, H.264 TS, split VOBs)
swift test                        # 15 tests: model + real ffmpeg conversions for every target and codec
./scripts/build_app.sh             # build/TinRoof Transcode.app
./scripts/make_screenshots.sh       # refresh docs/screenshots and the guide's images after UI changes
```

Optional ffmpeg with Hap encoding (Homebrew's ffmpeg lacks libsnappy):

```sh
./scripts/build_ffmpeg.sh                                   # installs vendor/ffmpeg
FFMPEG=vendor/ffmpeg/bin/ffmpeg ./scripts/build_app.sh      # bundles it in the app
```

You can also point the app at any ffmpeg in Settings → ffmpeg.

## Architecture

| Layer | Path | Role |
|---|---|---|
| `CFFmpeg` | `Sources/CFFmpeg` | System library module for libavformat/avcodec/avutil/swscale/swresample (pkg-config) |
| `CMedia` | `Sources/CMedia` | C shim: probing, keyframe and timecode-break indexing, decoding to BGRA and 48 kHz stereo float, the seven AC3 downmix modes as swresample matrices |
| `MediaCore` | `Sources/MediaCore` | Edit-decision model (cut/copy/paste/trim, undo), sources and split-file/DVD detection, export settings, the ffmpeg command builder, the job runner with progress, batch queue, presets, watermark rendering, downloader |
| `AppMain` | `Sources/AppMain` | AppKit player (video/audio engines on a shared host clock, J/K/L shuttle, keyboard map), menus, SwiftUI exporter, batch, log, info, edit list, settings and Open URL windows |

Playback decodes with libav directly, so MPEG-2, VOB, TS, AC3 and other formats that AVFoundation cannot play work in the player. Conversions run the `ffmpeg` executable as separate processes: lossless jobs use the concat demuxer with in/out points (stream copy), and re-encoding jobs build one filtergraph (concat of edit segments → deinterlace → crop → rotate → scale/zoom/pad → frame rate → field order → eq → watermark overlay).

## Feature mapping

| MPEG Streamclip 1.9.2 | This app |
|---|---|
| Open MPEG/VOB/TS/…, multi-file streams, split-recording detection, demuxed M2V + audio | Same, plus every format FFmpeg reads (MKV, WebM, MXF, ProRes, NotchLC, Hap, AV1, …) |
| Open DVD (VIDEO_TS, title choice) | Same (unencrypted discs only, as before) |
| Player: full screen, JKL, frame/keyframe stepping, skip buttons, loop selection, PID menus, AC3 audio modes | Same |
| Cut/copy/paste/trim/revert trimming, single undo, edit list, delete audio track | Same, with unlimited undo/redo; cuts are frame accurate for exports, GOP-snapped for lossless output |
| Convert to MPEG / TS (+MP2), Demux to M2V/AIFF/M1A/AC3 | Same, plus lossless remux to MP4 / MOV / MKV |
| Export to QuickTime / AVI / MPEG-4 / DV / Other Formats / Audio / Frame | QuickTime, MPEG-4, AVI, MKV/WebM, DV, MPEG-2 (DVD), Audio, Frame; ProRes, DNxHR, CineForm, Hap, AV1, VP9, HEVC, FFV1 and more |
| 2D-FIR scaler, interlaced scaling, motion-adaptive deinterlace, frame blending, field dominance, rotation, zoom, crop, adjustments, watermark, presets, preview | Same, through FFmpeg filters (lanczos/spline scaling, bwdif, framerate, fieldorder, eq, overlay) |
| 2-pass / multipass, B-frames, data-rate limit | Same |
| Batch list (hold, repeat, redirect, simultaneous tasks, completion script, Add Files) | Same |
| Fix timecode breaks, fix data breaks, Check Stream, Log | Same (timestamps regenerated by FFmpeg) |
| Open URL / download / YouTube etc. scrapers | Direct URLs over HTTP(S)/FTP; web pages through optional yt-dlp instead of hard-coded scrapers |

| Save as AVI QuickTime component, DivX codec adapter | Not needed: FFmpeg writes AVI/OpenDML and MPEG-4 Part 2 (Xvid-compatible) directly |

## Codec notes

- ProRes: encode (software `prores_ks`, hardware `prores_videotoolbox`) and decode, Proxy to 4444.
- Hap / Hap Alpha / Hap Q: decode always; encode requires an ffmpeg built with `--enable-libsnappy` (`scripts/build_ffmpeg.sh`).
- NotchLC: decode only. FFmpeg has no NotchLC encoder, and no open-source encoder exists.
- The exporter lists every codec and disables the ones the installed ffmpeg cannot encode.

## Distribution notes

The debug and `build_app.sh` builds link FFmpeg from Homebrew, so they run on Macs with Homebrew's ffmpeg installed. A self-contained release needs FFmpeg built for the deployment target and its dylibs copied into `Contents/Frameworks` (or static linking), plus Developer ID signing and notarization. Shipping FFmpeg built with `--enable-gpl` (x264/x265) makes the app subject to the GPL; build with LGPL-only components if that matters.
