Getting started

TinRoof Transcode (TRT) opens almost any video file, lets you cut out what you don't need, join clips together, and save the result in the format you want.

PlayerMPEG, VOB, TS, MP4, MOV, MKV, AVI and more, including files QuickTime Player can't open.
EditorCut, copy, paste, trim and join. Your original files are never changed.
Lossless converterRe-wrap or split video without re-encoding: full quality, at disk speed.
ExporterRe-encode to H.264, HEVC, ProRes, DNxHR, Hap, AV1 and more.
BatchQueue many conversions and let them run on their own.

When TRT starts, it shows an empty player. Click it to choose a file, drag a video file onto it, or choose File › Open Files… ⌘O.

Requirements: macOS 14 Sonoma or later on an Apple Silicon Mac. Nothing else needs to be installed.

Opening video

  • Click the empty player to choose a file, or drag and drop a file onto it or onto the app icon in the Dock.
  • File › Open Files… ⌘O opens each file in its own player window.
  • File › Open DVD… ⇧⌘O opens a disc or VIDEO_TS folder and asks which title to open. Copy-protected DVDs are not supported.
  • File › Open URL… ⌘U plays or downloads a video from the internet.

Recordings split into several files

DVDs, camcorders and TV recorders often split one recording into several files. TRT recognises them and offers to open all the parts as one stream:

DeviceExample files
DVDVTS_01_1.VOB, VTS_01_2.VOB, …
DreamBoxRecording.ts, Recording.ts.001, …
HumaxMovie~0.vid, Movie~1.vid, …
HomecastChannel.tp0, Channel.tp1, …

A video-only .m2v file automatically opens with the audio file of the same name (.aiff, .wav, .mp2, .ac3…).

The player

  • Timeline: the triangle is the playhead; click or drag to move it. The selection shows in blue and red lines mark joins and cuts.
  • Video PID / Audio PID: choose the video and audio track when a file has more than one. Tracks are listed by their PID (stream ID); hover over one to see its format.
  • Audio Mode: for 5.1 surround audio, choose Stereo Mix, Front Mix, Surround (Pro Logic), or a single channel pair.
  • Transport buttons: skip back, play backwards, play/stop, play forwards faster, skip forward, with the current time above them. Hold ⌥ for slow motion, one-minute skips, or looping the selection.
  • In ⇔ Out: the start and end of the selection, which Save As, Convert and Export use.
  • Trimming: the part of the stream shown in the player (see Trim, below).
  • Volume: ⌘↑ and ⌘↓.

Selecting and editing

Edits change only what you play, save or export. Your original files are never modified.

Make a selection

  1. Move the playhead to where the selection should start and press I.
  2. Move to where it should end and press O.

You can also Shift-drag along the timeline, or use Edit › Go to Time… ⌘G: type 1:00-2:00 to select from 1 to 2 minutes.

Edit commands

CommandWhat it does

The edit list

List › Edit List ⌘L lists each piece of the edited stream. Double-click a row to select that piece in the player.

How precise are edits?Exports are accurate to the frame. Lossless commands copy the video without re-encoding, so each piece starts on a keyframe, usually every half second for MPEG-2. Turn on Preserve GOPs at In/Out in Settings to keep, rather than drop, the partial piece at each cut.

Joining clips

To add a clip to the end of the one in the player, drag the file onto the player window. TRT asks what to do with it:

  • Append adds the new clip to the end of the current one.
  • Replace closes the current clip and opens the new one in the same window. Any edits to the current clip are discarded.

You can also choose File › Append Clip… ⌥⌘A, which appends without asking. You can drop or choose several files at once; they are added in name order.

  • Appending can be undone with ⌘Z.
  • Clips in the same format (for example, recordings from one camera or channel) can be joined with lossless commands such as Convert to MPEG or Save As.
  • Clips in different formats can be joined with any Export command. TRT scales and resamples them to match the first clip. A clip with no sound gets silence so the soundtrack stays in sync.
Joining with copy and pasteYou can also copy part of one file, open another, and paste it at the playhead.

Lossless conversion and Save As

Lossless commands copy the video exactly as it is: full quality, about as fast as copying the file. They save the selection (or everything, if nothing is selected), including your edits.

Convert to MPEG.mpgDVD-compatible; needs MPEG-1/2 video
Convert to MPEG with MP2 Audio.mpgChanges AC3/PCM audio to MP2
Convert to TS (with MP2 Audio).tsAny video codec
Convert to MP4 / MOV / MKV.mp4, .mov, .mkvAny codec, re-wrapped

The MPEG and M2V commands need MPEG-1 or MPEG-2 video. For anything else, such as H.264 from a camcorder, use Convert to MP4/MOV/MKV or an Export.

Damaged recordings

  • Edit › Fix Timecode Breaks finds jumps in the timing (common in VOB and TV recordings) and repairs them when you convert.
  • File › Check Stream decodes the whole file and lists any damage in the Log.
  • Fix streams with data breaks in Settings skips corrupt data instead of stopping.

Exporting

Exporting re-encodes the selection to a new format, size or codec. Choose an exporter from the File menu and adjust the settings. The preview on the right shows the current frame with your settings applied and updates as you change them. Then click Make Movie.

Software or Apple hardware?H.264, HEVC and ProRes each come in two versions. The plain versions run on the processor's cores and give the best quality for the file size. The (Apple hardware) versions use the video encoder built into Apple silicon: they are much faster, leave the processor free for other work, and are ideal when speed matters more than the smallest possible file. With H.264, HEVC or ProRes source video, TRT also decodes it on that hardware, so the whole export runs there.

Settings in the exporter

  • Compression: codec, quality or data-rate limit, multipass, B-frames, ProRes and DNxHR profiles.
  • Picture: frame size, frame rate and blending, field order, deinterlacing, rotation, zoom, cropping.
  • Sound: format, channels, sample rate, bit rate, surround downmix; Pass Through keeps the original audio.
  • Adjustments: brightness, contrast, saturation, volume, and a watermark text.
  • Presets: save all settings under a name and load them later.
Interlaced videoDVD and TV recordings are usually interlaced. Keep Interlaced scaling on to export for TV, or turn on Deinterlace video to watch on computers and phones.

Batch processing

The Batch List runs many conversions one after another, or several at once. Open it with List › Batch List ⌘B.

  • While the Batch List is open, Save As, Convert, Export and Download commands are added to it instead of running immediately.
  • Add Files… (or dropping files onto the list) applies one task to many files.
  • Go starts the queue. Hold skips a task, Repeat runs it again, and Redirect… changes where files are saved.
  • Simultaneous tasks is Automatic by default: TRT runs as many tasks at once as your Mac can take. Heavy encoders such as ProRes run one at a time, lighter ones such as VP9 two at a time, up to three Apple hardware encodes together, and two lossless copies. Choose a number instead to set it yourself.
  • Script… runs an AppleScript or app when everything is finished.

Troubleshooting

ProblemWhat to do
macOS won't open the appSystem Settings › Privacy & Security › Open Anyway.
A file won't openThe Log shows why. Encrypted DVDs and files with DRM can't be opened.
“Needs MPEG-1 or MPEG-2 video”Use Convert to MP4/MOV/MKV or an Export instead.
“Can't join clips in different formats”Lossless commands need matching clips. Use an Export to join them.
Lossless output starts slightly after the In pointIt starts on the next keyframe. Export instead for frame accuracy.
Lines on moving edgesThe video is interlaced: turn on Deinterlace video.
Exported picture is the wrong shapePick a frame size matching the shape in Stream Info (16:9 or 4:3).
4K playback stuttersLower Maximum display resolution in Settings.
Your files are safeTRT never changes the files you open. Every command writes a new file.
